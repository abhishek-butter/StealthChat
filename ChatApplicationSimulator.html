Research & Protocol Concepts

Key concepts used in our Web Chat Application architecture.

WebSockets (ws://)Unlike HTTP, WebSockets provide a persistent, full-duplex connection between the browser and server, essential for real-time chat.
Protocol BridgingBrowsers cannot connect directly to raw TCP sockets. The Node.js proxy bridges this gap by translating WebSocket frames into raw TCP byte streams for Java.
BroadcastingThe Java Server maintains a list of all active TCP sockets. When one client sends a message, it is written to every socket's OutputStream.
